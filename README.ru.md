# Дока 2 · Dota Offline League

Локальная лига Dota 2 для Windows. Выберите роль и героя, сыграйте матч 5 на 5 с четырьмя союзниками и пятью соперниками под управлением ботов. У Radiant и Dire могут быть свои тренеры. Рейтинг, статистика и доступные повторы собраны в истории лиги.

**[Игровой цикл и поведение ботов](docs/gameplay.ru.md)** · **[Запуск и диагностика](offline_league/README.md)** · **[Подключение тренеров](team_coach/README.md)**

## Как начать матч

Нужны Windows, установленная Dota 2 в Steam, Python **3.11 или новее** и подписка на [Open Hyper AI в Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3246316298). Дождитесь, пока Steam скачает скрипты ботов.

1. Закройте Dota и дважды нажмите [Играть.cmd](Играть.cmd). Лаунчер установит или обновит аддон и адаптер ботов, поднимет сервис лиги и оба сервера тренеров, затем откроет лигу внутри Dota.
2. Для игры с тренерами в двух видимых чатах отправьте [мастер-промпт](#промпт-для-двух-тренеров) один раз в локальном чате проекта. Дождитесь готовности обоих тренеров. Для автоматического управления локальными правилами запустите `.\Играть.cmd -CoachMode rules`.
3. Настройте сложность, выберите позицию и нажмите **Найти матч**. Героя выберите на игровом экране пика.
4. После матча проверьте сохранённую таблицу и нажмите **Вернуться в лигу**. Откройте запись в **Истории матчей**, чтобы посмотреть статистику и запустить повтор, если файл записи доступен.

Для входа из обычного меню Dota запустите `.\Играть.cmd -FromDotaMenu` и введите `offline_league` в игровой консоли. [Настройка входа из меню](offline_league/README.md#запуск-из-меню-dota)

## Промпт для двух тренеров

Отправьте его в чате этого проекта на компьютере с запущенной лигой. Нужны доступ к локальному терминалу и возможность создавать или возобновлять видимые чаты.

```text
Подключи тренеров лиги «Дока 2» в двух отдельных видимых чатах проекта.
Создай «Тренер Radiant» и «Тренер Dire» или возобнови их, если они уже существуют.
Рабочая папка каждого чата — корень этого репозитория.

Тренер Radiant читает team_coach/player-team-session.txt и подключается к
127.0.0.1:32125. Журнал — %LOCALAPPDATA%\Dota Offline League\coach-events.jsonl.
Тренер Dire читает team_coach/opponent-team-session.txt и подключается к
127.0.0.1:32126. Журнал — %LOCALAPPDATA%\Dota Offline League\dire-coach-events.jsonl.

В каждом чате через /status проверь свою сторону и режим observe. Подставь
полный путь к журналу и жди новый session_id матча через
python -X utf8 -m team_coach.watch "<путь к журналу>" --port <порт стороны> --follow.
Веди свою команду по её телеметрии и текущим настройкам тренера. Оставайся
на связи до конца матча и разбери, какие приказы приняли, что команда
успела выполнить и где пришлось менять план.

Подтверди готовность здесь, когда оба чата начнут ждать матч.
```

В союзном командном чате попробуйте `!пуш топ`, `!пуш мид`, `!пуш бот`, `!рош` или `!отмена`. [Команды игрока и примеры тактики](docs/gameplay.ru.md#что-умеют-боты)

## Проверки

Из корня репозитория запустите тесты на Python и проверку итогового экрана на Node.js.

```powershell
python -B -m unittest discover -s offline_league -p 'test_league_server.py'
python -B -m unittest discover -s tests -p 'test_team_coach*.py'
node offline_league/test_league_result.js
```
