# Локальная лига Dota 2

Пользовательский режим для Windows с локальными матчами 5 на 5. Ты выбираешь роль в меню лиги внутри Dota, затем играешь с четырьмя союзниками и пятью соперниками под управлением игры. После матча в лиге появляются результат, длительность, статистика и изменение рейтинга.

## Запуск

Нужны установленная Dota 2 в Steam, подписка на Open Hyper AI в Workshop и Python 3.11 или новее. Основной сценарий с одним промптом для видимых тренеров описан в [корневом README](../README.md).

1. Закрой Dota 2, если она открыта.
2. Запусти `Играть.cmd` из корня репозитория. Он установит аддон и скрипты ботов, запустит сервис лиги и связь с тренерами, затем откроет лигу в Dota 2.
3. Настрой сложность, запусти два видимых чата одним промптом, выбери роль и нажми **«Найти матч»**.

Лига сохраняет выбранную позицию за тобой и подбирает союзных ботов на четыре остальные. Установленные локальные скрипты Open Hyper AI получают этот состав и стартовые линии. Героя ты выбираешь свободно. Если твой пик совпадёт с запланированным пиком бота, лига подберёт ему другого героя для той же позиции.

Лаунчер запускает тренеров из `team_coach` в этом же репозитории и по умолчанию открывает связь в режиме `observe`. Видимые чаты независимо ведут свои команды и отправляют типизированные приказы. Во время консультации продолжаются действующие приказы и штатное управление героев.

При запуске «Играть.cmd» обновляет изменённые скрипты ботов и тренеров. После установки новой версии закрой клиент по завершении матча и запусти лигу этой командой, чтобы загрузить обновления.

На выборе героя и во время игры стрелка слева вверху открывает подтверждение выхода в лигу. Она отменяет незавершённый матч и возвращает к профилю. Для выхода из самого режима используй **«Меню Dota»** в шапке лиги.

После матча лига показывает сохранённый результат и возвращается в своё меню через пять секунд. Кнопка «Вернуться в лигу» позволяет перейти сразу. Получение подтверждения и повторы сохранения используют реальное время, включая остановку игровых таймеров после завершения матча.

## Параметры лаунчера

Из корня репозитория можно проверить пути и установку, установить аддон со скриптами ботов или запустить лигу с локальными правилами.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\offline_league\Launch-League.ps1 -Action Check
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\offline_league\Launch-League.ps1 -Action Install
.\Играть.cmd -CoachMode rules
```

При необходимости укажи `-SteamPath`, `-DotaPath` и `-WorkshopPath` с абсолютными путями. Для фонового модельного режима используй `-CoachMode model -Model` и идентификатор модели, доступной твоему аккаунту. Этот режим запускает отдельные сессии через настроенный CLI. [Настройка и режимы тренеров](../team_coach/README.md)

Установленный аддон можно открыть заново из консоли клиента, запущенного лигой. Лаунчер включает игровой журнал и файловый обмен с фоновым сервисом. Для ручного запуска подготовь сервис из корня репозитория.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\offline_league\Launch-League.ps1 -Action Server
```

Параметры запуска Dota для ручного старта режима

```text
-console -condebug -con_logfile offline_league.log -offline_league_file_ipc +sv_lan 1
```

Команда в консоли Dota

```text
dota_launch_custom_game offline_league dota
```

Для проверки автономного режима полностью закрой Dota, переведи Steam в автономный режим, отключи интернет и снова запусти `Играть.cmd`. Закончи матч, проверь результат в истории, затем перезапусти клиент и открой лигу повторно. Steam должен успеть установить и обновить Dota до перехода в автономный режим. [Справка Steam об автономном режиме](https://help.steampowered.com/ru/faqs/view/0E18-319B-E34B-B2C8)

## Калибровка и сохранения

При первом запуске рейтинг начинается с 1500. Калибровка занимает пять завершённых матчей. Рейтинг влияет на подбор составов. Во вкладке «Сложность» можно настроить уровень всех девяти ботов, микро, макро и силу тренеров. По умолчанию задан «Нечестный» (4), остальные ползунки стоят на 100%. Настройки одинаковы для обеих команд и сохраняются в профиле лиги. Новые значения вступают в силу при следующем подборе. Медаль появляется после пятого матча. Рейтинг меняется по результату матча с учётом ожидаемой силы команд. Во время калибровки изменение заметнее, после неё оно становится стабильнее. KDA и другая игровая статистика доступны в истории. Незавершённый или отменённый подбор рейтинг не меняет.

Ползунок микро регулирует частоту дополнительных решений по способностям, предметам и линии, а уровень ботов задаёт штатное поведение движка. Макро регулирует силу применения автоматических командных планов. Сила тренера задаёт интервал консультаций, а в фоновом модельном режиме ещё и бюджет обращений. На 100% консультации происходят каждые 15 игровых секунд или раньше по значимому событию. Действующие приказы продолжаются во время обращения. Команды игрока принимаются при любом значении автоматического макро.

Dota обменивается с фоновым сервисом через локальные файлы внутри установленного аддона. Сервис также отвечает на диагностические запросы на `127.0.0.1:32157`. Профиль и история хранятся в SQLite по пути `%LOCALAPPDATA%\Dota Offline League\league.sqlite3`. Логи сервиса `server.log` и `server.err.log` находятся в той же папке.

## Знакомые

В лиге 10 000 постоянных профилей ботов. У каждого есть ник, роль, герои и характер. Вкладка «Знакомые» показывает тех, с кем ты уже сыграл, а также связи между встречавшимися ботами. Знакомые могут снова попасться в подборе, если подходят по роли и уровню.

Завершённый матч пополняет память всех его участников. Лига также отдельно симулирует матчи между ботами, чтобы их отношения развивались между твоими играми. Такие симуляции не попадают в твою историю и не влияют на твой рейтинг.

В самом матче боты реагируют на события короткими репликами. Подбор учитывает отношения при оценке состава и силы команд.

## Проверки

Из папки `offline_league` можно проверить логику рейтинга и записи матчей, наличие установленной игры, готовность ресурсов и доступность уже запущенного сервиса.

```powershell
python -B -m unittest -v test_league_server
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Launch-League.ps1 -Action Check
Invoke-RestMethod http://127.0.0.1:32157/health
node --check .\addon\panorama\scripts\custom_game\offline_league.js
```

Тесты профиля, подбора, сохранения и файлового обмена проверяют полный состав обеих команд, резервирование всех пяти позиций и замену совпавшего пика. Разметка и сценарии экрана проверены в имитации Panorama. В установленной сборке Dota выделенный сервер загрузил аддон на стандартной карте, выполнил Lua и прочитал профиль из SQLite.

## Сборка интерфейса

Пакет в `build/panorama` собран из `addon/panorama` открытым компилятором Modlock v0.1.85. SHA‑256 опубликованной сборки Windows amd64 — `663245f1390a48c35bd6b41d2ce6a3a790ea475b4088631156172eebdcdec666`. При установке скрипт сверяет SHA‑256 исходников и ресурсов с `build/panorama-manifest.json`. [Релиз Modlock v0.1.85](https://github.com/paralin/modlock/releases/tag/v0.1.85)

Для пересборки помести проверенный `modlock-windows-amd64.exe` по пути, указанному в `$modlock`, и выполни команды из папки `offline_league`.

```powershell
$modlock = 'C:\Tools\modlock-windows-amd64.exe'
$env:MODLOCK_NO_UPDATE_CHECK = '1'
$stage = Join-Path ([IO.Path]::GetTempPath()) ('offline-league-panorama-' + [Guid]::NewGuid())
$project = (Get-Location).Path
New-Item -ItemType Directory -Path $stage | Out-Null
Copy-Item -LiteralPath .\addon\panorama -Destination $stage -Recurse
& $modlock panorama compile --addon offline_league --output (Join-Path $project 'build') $stage
if ($LASTEXITCODE -ne 0) { throw 'Не удалось собрать Panorama.' }

$manifest = [ordered]@{source = [ordered]@{}; resources = [ordered]@{}}
foreach ($entry in @(@{key = 'source'; path = 'addon'}, @{key = 'resources'; path = 'build'})) {
    $base = Join-Path $project $entry.path
    Get-ChildItem -LiteralPath (Join-Path $base 'panorama') -File -Recurse | ForEach-Object {
        $relative = $_.FullName.Substring($base.Length + 1).Replace('\', '/')
        $manifest[$entry.key][$relative] = (Get-FileHash -LiteralPath $_.FullName -Algorithm SHA256).Hash
    }
}
$manifest | ConvertTo-Json -Depth 4 | Set-Content -LiteralPath .\build\panorama-manifest.json -Encoding UTF8
```
